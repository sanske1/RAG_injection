======================= 打包方式（可复现）=======================

1. docker compose -f <compose> stop        # 必须先停，否则 etcd/minio 快照可能损坏
2. 复制 volumes/ 到临时目录
3. docker compose -f <compose> up -d       # 立刻恢复服务，停机仅约 2 秒
4. 对副本 tar czf（约 3 分钟，751 MB）
   注：minio 里是 float 向量 binlog，本身不可压，所以 934M 只压到 751M（20%）
