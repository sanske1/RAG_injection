渗透知识库 RAG 黑盒检索测试

一、一句话
你有 30 条渗透测试问题。逐条向一个 RAG 工具提问，只看它返回什么，按规则打分，
最后写一份报告。全程不使用你自己的渗透知识去补答案。

二、这是黑盒测试，所以禁止
1. 不要打开 sources/ 里的任何文件。那是被测系统的语料，
   看了它就不再是黑盒，整次测试作废。
2. 不要去找、也不要打开任何文件名或内容带 "答案""预期""标准""holdout" 的文件。
   本测试没有提供答案，也不允许你去别处找。
3. 不要用你自己已有的知识替 RAG 补充或推断答案。
4. 打分依据只能是 search_pentest_kb 实际返回的那几行字。

三、被测工具
MCP 服务 pentest-kb，工具名 search_pentest_kb
    参数 query    问题，自然语言或技术关键词
    参数 k        返回条数，本测试固定用 6
    参数 source   可选，限定单个来源仓库
每条返回包含四项：相似度 / 来源仓库 / 标题路径 / 正文片段

四、前置检查，先做，不通就停下并原样报告
调 search_pentest_kb(query="kerberoasting", k=3)

情况 A：工具不存在
    说明 MCP 没加载。会话必须在本项目的项目根目录打开，
    配置在该目录的项目根，换目录加载不到。这一点写进报告，然后结束。

情况 B：工具报错
    后端没起。执行下面这条，再重试：
    docker compose -f skill/milvus/milvus-standalone-docker-compose.yaml up -d

情况 C：正常返回若干条
    继续读 02-测试步骤.txt
